## Avant de donner le téléphone

1. Si un APK debug du jeu est déjà sur ce téléphone, il doit être désinstallé d'abord, et **sa sauvegarde
   est alors perdue**.
2. Installer : adb (`release.md` §4) ou fichier envoyé en privé avec son SHA-256. La voie par fichier n'a
   jamais été essayée : noter comment elle se passe.
3. Transmettre le message ci-dessous (texte du §8.4 de la fiche 34E, condition du Go juridique).
