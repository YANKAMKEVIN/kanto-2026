# CV-FX 2 — effets peints du lot P1 : à regarder

Fiche : `../serie-cv-fx-2.md`. Classement des attaques : `docs/tech/combat-vivant-lots.md`.

**À regarder en premier : `planche.png`** (12 flipbooks sur fond de combat sombre, au mélange du jeu, puis 24
particules), puis **les GIF en boucle** (un par flipbook) : une animation se juge en mouvement.

Ce qui compte pour ton avis :
1. **Les boucles se referment-elles bien ?** (`tourbillon_vent`, `aura_montante`, `jet_sable`, `lianes_fouet`, `nuage_poison`).
2. **Les effets de matière** (poison violet, fumée, sable, bulles) **tiennent-ils sur un fond de décor ?** Le détourage est
   fait à partir d'un fond vert (poison, cœur, psy) ou magenta (le reste) ; une frange claire serait à signaler.
3. **Le cœur (Grobisou), rejeté en vague 1, est refait** (`coeur`, rose vif).
4. Pour chaque identifiant : **retenu**, ou **à reprendre** (une phrase suffit).

Pas encore fait, volontairement (le lot P1 n'en a pas besoin) : explosion, rayon d'énergie, rayon de glace, vague, ombre
spectrale, flamme de dragon. Rien n'est branché au jeu.
