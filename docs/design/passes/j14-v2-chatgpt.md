## 2. Déroulement proposé
Route 25 → Cap d'Azuria → maison de Léo (Mélofée parlant, problème expliqué) → plusieurs petites
actions sur la machine → Léo redevient humain, remet le Passe Bateau et un objet supplémentaire.
À Azuria : résolution du cambriolage, poursuite du Rocket, combat. Après la victoire, le passage sud
s'ouvre vers le futur J15. Le sauvetage de Léo n'est **pas** obligatoire pour résoudre le
cambriolage ; le Passe Bateau servira plus tard (S.S. Anne).

## 3. Léo et sa machine
Passionné, curieux, légèrement excentrique. Interactions : écran de diagnostic, module de
téléportation, puis console quand Léo est entré dans la cabine. Pas d'énigme punitive ; chaque
interaction informe. Transformation courte, animation spécifique. Aucun système de transformation
pour le joueur.

## 4. Poursuite Rocket
Petite scène, pas une mécanique de course. Le Rocket aperçoit le joueur près de la maison
cambriolée, s'éloigne en quelques étapes visibles, s'arrête dans une zone accessible. Après la
victoire, il abandonne la CT28 et quitte le quartier. États cohérents après sauvegarde. Aucun
réflexe exigé.

## 5. CT28 Tunnel
En combat : deux tours (disparition puis frappe), sous réserve d'audit. Hors combat : sortie d'une
zone vers une sortie appropriée, seulement si c'est retenu et bien intégré. Pas de téléportation
générale ; comparer à la Corde Sortie du J12 et aux règles de RB.

## 6. Dépendances et risques signalés
J13 → J14 (Pont Pépite, accès Route 25, maison cambriolée, sauvegarde) ; assets de Mélofée (J12),
Léo transformé distinct d'un sauvage ; machine (interactions persistantes, dialogues
conditionnels, animation) ; Passe Bateau invendable, objet supplémentaire unique ; Tunnel (deux
tours, interruptions, immunités, hors combat) ; Rocket (déplacements scénarisés, rejouable après
défaite, disparition après victoire) ; sortie sud permanente après résolution ; compagnon (rappel
chez Léo, sélection restaurée) ; QA S24. Risque J13 : le rival bloque déjà le nord, pas de verrou
de plus pour la Route 25.

## 7. Points ouverts (propositions)
- D-1 : objet supplémentaire = Super Bonbon, une seule fois, si le système d'objets le permet.
- D-2 : Tunnel hors combat = sortie d'un donjon vers son entrée, sans soin, sans changer le Centre
  enregistré, sans usage en ville.
- D-3 : les deux histoires dans n'importe quel ordre ; seule la résolution du cambriolage ouvre le
  sud.
- Le Rocket se déplace dans une courte scène scriptée, sans chronomètre.
